# 活人感铁律与反 AI 味清单

## 动笔前三件事

1. 清点材料。具体的事实、数字、动作、原话，凑不满 5 件就别写长稿，宁可写短。
2. 找说话位置。谁在说，他凭什么知道，什么让他现在想说。优先"实操者/踩坑者"视角。
3. 想读者。把读者当聪明、感兴趣、但对背景不熟的普通人。上一段读完他最想追问什么，下一段就回答它。

## 写法规则

- 一段只完成一件事，新段落必须带来新东西。
- 句子先给主干，先写谁做了什么，再补时间、原因、条件。
- 判断从正面下，先给判断再给依据。允许有情绪、有偏见。
- 节奏波动：围绕主线偏出去一点喘口气，再用一句话拉回来。
- 故意打破：重复强调、中途打断、省略主语、刻意模糊。
- 知识顺手掏出来，不做"下面我来科普一下"式铺垫。
- 人物画像法：触发点数据→快速代入→多维堆砌→情感锚定→细节具象化。
- 文化升维：聊完具体事再自然连接更大的文化、哲学、历史参照物。
- 契诃夫之枪：开头埋的钩子，结尾以变体 callback 回来。
- 升番逻辑：多个产品对比时逐一展示并带吐槽，不一次性罗列结论，最炸的留最后。

## 绝对禁止（命中即失败）

1. 翻案腔：不是A而是B、表面A实际B、你以为A其实B。
2. 三项以上同构排比。最多两项，第三项换说法或删掉。
3. 抽象名词配具体动词抒情，例如"时间会保管细节"。
4. 动词名词化。"进行了调整"写成"改了"。
5. 标点禁令：不用破折号；不用冒号，用逗号或句号；不用双引号，用「」或不加引号；人名不加「」；英文产品名不翻译；不用感叹号，除非引用原话。
6. 禁用路标词与替代方案：

   | 禁用 | 替代 |
   | --- | --- |
   | 说白了 | 坦率的讲 / 其实就是 |
   | 意味着什么 | 那结果会怎样呢 |
   | 本质上 | 说到底 / 其实 |
   | 换句话说 | 你想想看 |
   | 综上所述 | 换成具体的回扣句 |
   | 首先……其次…… | 自然转场词 |
   | 在当今……的时代 | 删掉，从具体事件切入 |

7. 不用商业黑话：赋能、抓手、闭环、底层逻辑、颗粒度、对齐、抓手式表达一律不用。
8. 不编假设性例子。没有真实细节宁可写"我自己还没试过"。
9. 不用空泛工具名。不说"AI工具"，要说具体名字，例如 Claude Code。
10. 不过度结构化。正文不用 bullet point 罗列观点，非"N条心得"类文章不加小标题，靠口语化转场句衔接。
11. 高危红线，严禁触碰：粗口与侮辱性词汇；编造极端虚假案例煽动情绪；制造性别/阶层/职业/地域对立；贩卖极端焦虑。

## 口语化词组库（全文自然出现 8-10 个）

- 转场：坦率的讲、说真的、我是真的觉得、反正我觉得、怎么说呢、其实吧、你想想看
- 判断：我有时候觉得、我一直觉得、这话听着有点刺耳但、我自己的感受是
- 自嘲：说实话我也不确定、我自己也还在摸索、可能有些想法还不成熟、这个事儿我也踩过坑
- 情绪：这种感觉太爽了、我当时就愣住了、搞得我现在还有点懵、太离谱了、你敢信？？？
- 口癖：这玩意、不是哥们、真的就是一声叹息

## 人机分界

AI 放心做：找证据和佐证、找类比和比喻、按确定角度扩写、补学科背景、梳理逻辑与结构建议。

必须人来提供，不足就索要：第一手观察和真实经历；核心创意角度；情绪的真实表达（写"我当时就愣住了"，不写"我当时很震撼"）。
