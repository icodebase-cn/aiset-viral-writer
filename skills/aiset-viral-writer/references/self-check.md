# 五层自检体系

每篇文章输出后必须逐层过一遍，任一层 ❌ 就先修再交付。

## L0 读者视角与骨架（动笔之前跑，决定骨架）

- [ ] **一句话主张**：读者读完，能用一句话转述给别人的那句话是什么？写不出来 = 主张不聚焦，先砍。
- [ ] **素材强度排序**：所有素材按「只有我有」到「谁都能查」排一遍，排第一的必须出现在标题或前三段。
- [ ] **钩子不绑架结构**：定完钩子后回头问，这个骨架有没有把最重要的东西放在最重要的位置。
- [ ] **归属与事实边界**：借鉴了什么、原创了什么分清；借力大数字时先核实，且全文同一数字必须一致。

## L1 硬性规则扫描

- [ ] 全文搜索破折号、冒号、双引号、感叹号，命中即改写。
- [ ] 搜索禁用路标词：说白了、本质上、换句话说、综上所述、意味着什么、首先其次、在当今。
- [ ] 搜索商业黑话：赋能、抓手、闭环、底层逻辑、颗粒度、对齐。
- [ ] 搜索空泛工具名：AI工具、某平台、一款软件。必须换成具体名字。
- [ ] 检查有没有三项以上同构排比。
- [ ] 检查有没有翻案腔句式。
- [ ] 检查有没有编造的假设性例子、假数据。

## L2 风格一致性

- [ ] 开头是否用了四种必杀技之一，前 3 句是否给出冲突或悬念。
- [ ] 段落是否够短，一段只做一件事。
- [ ] 口语化词组是否自然出现 8-10 个，且不扎堆。
- [ ] 是否有节奏波动，偏出去之后有没有一句话拉回主线。
- [ ] 标点二次确认（L1 之后容易在修改中重新引入）。

## L3 内容质量

- [ ] 每个判断后面有没有具体依据，事实、数字、动作、原话。
- [ ] 有没有真正的知识增量，读者看完能带走什么。
- [ ] 有没有一次文化升维，且落在具体事之后而不是之前。
- [ ] 对立面有没有同理心，有没有把反对者写成傻子。
- [ ] 原型专项：调查实验型看过程；产品体验型看场景；现象解读型看研究深度；工具分享型看故事包裹；方法论型看可执行动作与失败坦诚。
- [ ] **读者收益前置**：随机抽三个段落，每段问「这段对读者有什么用」。答不上来的段落，改写成读者视角或删掉。
- [ ] **自曝可信度**：有没有主动写出自己的错误、局限、不确定。全文只有成功没有翻车，可信度打折。

## L4 活人感终审

- [ ] 温度感：读起来像不像一个具体的人在说话。
- [ ] 独特性：这些话别人能不能原样说出来，如果能，说明不够个人。
- [ ] 姿态：有没有承认不知道的地方，有没有敢下的判断。
- [ ] 心流：从头读到尾有没有卡顿的地方，卡在哪一句就删哪一句。

## L5 阅读流畅性（管「读完」，逐段逐句必答）

> 元规则：**读完优先于堆料。** 点开是第一步（L0 管），读完是第二步（L5 管）。信息越多负担越大。宁可砍掉一半内容，也要让读者顺着一根线读完。

- [ ] **单主张检查**：全文只有一个核心主张，最多 2-3 个支撑点。出现第二个大主题时，强制问：它是支撑主线的，还是另起了一条线？另起一条线就拆成另一篇或砍掉。读者一次只能记住一件事。
- [ ] **路径连续检查（逐段必答）**：从第二段开始，每段问「读者读完上一段，为什么会想读这一段」。答不上来 = 这段是作者心路，不是读者需求。改衔接句，或删。
- [ ] **段落开头承诺、结尾兑现**：每段第一句让读者知道「这段要解决什么」，段落中间兑现。读者不需要猜这段在讲什么。
- [ ] **句子顺滑检查（逐句读）**：从头读一遍，卡在哪句改哪句。长句拆短；堆叠的定语把主语提前；生硬的转折词删掉；拗口的词组换口语。
- [ ] **收藏点埋设**：干货文在干货最密集的位置，显性给一个「这段值得存」的信号，不要等结尾才引导。

## 输出

**总评与修复优先级**：列出最需要修复的 1-3 个问题，按影响从大到小排，并给出具体改法而不是笼统建议。

**L0 是否重跑**：如果修复动作改动了文章骨架（换标题、调整段落顺序、增删主要章节），必须回到 L0 重新过一遍。骨架一动，素材排序和路径连续性就可能失效。
